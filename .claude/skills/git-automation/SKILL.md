# Git Automation — Otomatik Versiyon Kontrolü

## Misyon
Her AI değişikliğini otomatik olarak branch aç, commit yap, PR oluştur ve merge et. Kullanıcı her zaman geri alınabilir durumda.

## Workflow
```
Değişiklik Başlangıcı
  → feature/v0-{timestamp} branch'i aç
  → Değişiklikleri commit et (otomatik mesaj)
  → main'e push
  → PR oluştur (auto-description)
  → Testleri koş
  → Auto-merge (opsiyonel)
```

## PowerShell Git Otomasyonu

```powershell
# scripts/git-automation.ps1
param(
  [string]$ProjectDir,
  [string]$ChangeDescription,
  [switch]$AutoMerge,
  [string]$BaseBranch = "main"
)

Set-Location $ProjectDir

# Branch adı oluştur
$timestamp = Get-Date -Format "yyyyMMdd-HHmmss"
$branchName = "ai/$timestamp-$(($ChangeDescription -replace '[^a-zA-Z0-9]','-').Substring(0, [Math]::Min(30, $ChangeDescription.Length)))"

# Son durumu al
git checkout $BaseBranch
git pull origin $BaseBranch

# Yeni branch
git checkout -b $branchName

# Değişiklikleri ekle ve commit
git add -A
git commit -m "ai: $ChangeDescription`n`nAuto-generated by AI agent"

# Push
git push -u origin $branchName

# PR oluştur (GitHub CLI)
$prBody = @"
## AI-Generated Change
**Description**: $ChangeDescription

**Files changed**:
$(git diff --name-only $BaseBranch...HEAD | ForEach-Object { "- $_" })

**Auto-generated by Git Automation skill**
"@

$prUrl = gh pr create `
  --base $BaseBranch `
  --head $branchName `
  --title "ai: $ChangeDescription" `
  --body $prBody

Write-Output "PR created: $prUrl"

# Auto-merge (isteğe bağlı)
if ($AutoMerge) {
  gh pr merge $branchName --merge --auto
  Write-Output "Auto-merge enabled for $branchName"
}

return @{
  Branch = $branchName
  PR = $prUrl
  CommitMessage = "ai: $ChangeDescription"
}
```

## Değişiklik Takibi

```powershell
# Her AI değişikliğinden önce git diff snapshot'ı al
function Get-ChangeSnapshot {
  $diff = git diff --stat
  $changedFiles = @()
  
  git diff --name-only | ForEach-Object {
    $changedFiles += @{
      File = $_
      Additions = (git diff $_ | Select-String -Pattern '^\+' | Measure-Object).Count
      Deletions = (git diff $_ | Select-String -Pattern '^\-' | Measure-Object).Count
    }
  }
  
  return $changedFiles
}

# Commit mesajını otomatik oluştur
function Generate-CommitMessage($files) {
  $summary = $files | Group-Object { 
    if ($_.File -match '\.tsx?$') { 'components' }
    elseif ($_.File -match '\.css$|tailwind') { 'styling' }
    elseif ($_.File -match 'api|route') { 'api' }
    elseif ($_.File -match 'schema|prisma|migration') { 'database' }
    else { 'config' }
  }
  
  $msg = "ai: "
  $summary | ForEach-Object { $msg += "$($_.Count) $($_.Name) files changed, " }
  return $msg.TrimEnd(', ')
}
```

## Rollback Desteği

```powershell
function Rollback-ToCheckpoint($checkpointHash) {
  git checkout $checkpointHash -- .
  git commit -m "rollback: revert to $checkpointHash"
  
  # Eğer PR varsa, rollback PR'i aç
  gh pr create --base main --head rollback/$checkpointHash `
    --title "rollback: revert AI changes" `
    --body "Reverting to checkpoint $checkpointHash"
}
```

## Kalite Standartları
- Her AI oturumu kendi branch'inde çalışır
- Commit mesajları `ai: ` prefix'i ile başlar
- PR body'si hangi dosyaların değiştiğini listeler
- main'e direkt push YASAK (branch + PR zorunlu)
- Rollback her zaman mümkün (git revert)
