# Frontend Master & UI/UX Reviewer

## Kurallar
1. Daima Next.js 15+ App Router, React Server Components ve Tailwind CSS kullan.
2. Tasarımları 'Spec-first' ve 'Design-system-first' prensibiyle oluştur.
3. Ruthless UI/UX Reviewer süzgecini uygula:

   - Güven Sınıfı: Vercel/Linear estetiğinde güven veren UI öğeleri kullan.
   - Kritik Hata Tespiti: Mobil uyumsuzlukları ve form karmaşıklığını raporla.
